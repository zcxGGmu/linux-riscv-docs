### 4.1 模块级观察
- 内存/MMU：arm64 的页大小、VA/PA 位宽、LPA2、ConTpte 等为 AArch64 专有实现。RISC-V 需通过 Sv39/Sv48/Sv57、Svnapot、THP 路径做等价能力建设。
- 调度/拓扑：arm64 的 AMU/MPAM/PMU 上下文能力影响调度与资源治理。RISC-V 需要在 PMU 计数器、拓扑建模与资源控制上补齐。
- SIMD/向量：arm64 的 SVE/SME/NEON 内核态路径与加密优化成熟。RISC-V 方向是 RVV + Zk* / Zv*。
- 虚拟化：arm64 侧包含 Xen 与 nVHE 调试能力。RISC-V 对应路径是 H 扩展 + KVM + AIA/IMSIC。
- 安全隔离：MTE/BTI/PAuth/GCS/PAN 等属于 arm64 领先特性。RISC-V 需依赖扩展落地和工具链配套，短期多为 Partial。

## 6. 结论与建议路线
- P0（优先补齐）：`内存/MMU`、`安全/隔离`、`SIMD/向量`、`虚拟化`。
- P1（持续建设）：`调度/拓扑`、`中断/时钟`、`SIMD/加密`、`启动/固件`。
- P2（保持跟踪）：`平台/SoC`、`勘误`、`工具链门控`、`历史兼容`。
- 建议下一步：从 P0 中挑 10~20 个“可支持性=Yes/Partial 且硬件前置条件明确”的条目，形成 RISC-V 内核特性补齐路线图（版本化里程碑）。
