💡 数据洞察与关键发现

  • 🚀

    绝对性能层级

    ARM 架构在所有 JDK 版本中均保持绝对领先地位，其峰值吞吐量稳定在 RISC-V 的 2.0 至 2.3 倍之间，这与 ARM 拥有更多核心（96 vs 64）及更高的总聚合算力直接相关。

  • 📈

    ARM JDK 演进特征

    JDK 25 (1,029k) 成功恢复了 JDK 17 (1,033k) 的高峰值水平，走出了 JDK 21 (999k) 略微回落的低谷。但在超高负载（128仓库）下，JDK 21 依然保持了最好的稳定性（衰减最少）。

  • 📉

    RISC-V JDK 性能回落

    与 ARM 不同，RISC-V 在 JDK 25 上出现了明显的峰值性能回落，从 JDK 17/21 的 ~495k 下降至 ~447k (-10%)。这表明该架构在 JDK 25 的特定新特性适配上可能存在暂时的开销。

  • ⚖️

    极致的负载稳定性

    尽管 RISC-V JDK 25 峰值较低，但它展现了极强的抗压能力。在超过最佳并发数（64）后，直到 128 仓库，其性能几乎没有任何衰减（保持率 99.7%），形成了一条完美的“平顶”曲线。

  • 🧩

    核心效能分析

    剥离核心数量差异（ARM 64核 vs RISC-V 64核），RISC-V 的单核平均贡献效率约为 ARM 的 1.4 倍。这意味着 RISC-V 目前的性能瓶颈主要在于核心规模，而非单核能力。
