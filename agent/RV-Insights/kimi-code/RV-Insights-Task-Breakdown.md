# RV-Insights 阶段任务清单（细粒度）

> **版本**：v3.0 落地版  
> **目标**：基于 v3.0 设计方案，拆分为可直接分配开发的细粒度任务  
> **原则**：每个任务应能在 0.5-3 天内独立完成，有明确的输入/输出和验收标准

---

## 任务清单结构

```
里程碑 M0：项目基础设施（开发环境 + CI/CD + 基础框架）
里程碑 M1：数据层 + RAG 知识库（数据库 + 向量库 + 知识库建设）
里程碑 M2：Agent 基础设施（SDK集成 + MCP网关 + Prompt引擎 + 弹性架构）
里程碑 M3：探索Agent（邮件列表 + 代码库分析 + 可行性验证）
里程碑 M4：规划Agent（方案设计 + 任务拆解 + 依赖分析）
里程碑 M5：开发Agent（代码生成 + Git工作流 + 编译自检）
里程碑 M6：审核Agent（代码审查 + 迭代修复 + 语义分析）
里程碑 M7：测试Agent（环境搭建 + QEMU测试 + 静态分析）
里程碑 M8：HITL系统（状态机 + 通知 + Web UI审核面板）
里程碑 M9：反馈闭环 + 社区集成（学习系统 + 自动提交）
里程碑 M10：可观测性 + 运维（监控 + 告警 + 部署）
里程碑 M11：集成测试 + 验收（端到端测试 + 性能基准）
```
