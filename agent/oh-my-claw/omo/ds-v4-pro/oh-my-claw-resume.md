# oh-my-claw 项目介绍

`oh-my-claw` 是一个面向 `openclaw` 多通道 AI 网关平台的智能增强层，设计目标是将基础 AI 网关升级为具备**多智能体编排、自愈恢复、质量管控与任务路由**能力的工程化智能体平台。

项目延续了 `oh-my-openagent` 的增强思路，采用**插件化集成**方式接入宿主系统，不侵入宿主源码，通过 openclaw 提供的插件机制、Hook 生命周期、Subagent 能力、Skill 系统与 MCP 生态，在本地网关和多远程通道场景中构建可扩展的 AI 协作体系。

从产品定位上看，`oh-my-claw` 不只是“给 AI 助手增加几个工具”，而是为多模型、多角色、多任务场景提供统一编排框架，使系统具备更强的**任务分发能力、恢复能力、执行稳定性和交付质量保障能力**。

# 功能特性（简历版）

## 项目简介版
- 面向 `openclaw` 多通道 AI 网关的插件式增强系统，构建多智能体协作、任务路由与质量治理能力。
- 基于宿主 28 个 Hook 生命周期实现非侵入式扩展，支持 agent、tool、session、subagent、gateway 等关键流程接管与增强。
- 结合多模型调度、Skill 加载、MCP 工具接入与上下文管理能力，打造适用于复杂任务执行的工程化 AI 平台。

## 功能亮点版
- **多智能体编排**：设计专家角色体系，为不同任务分配专属 agent、Prompt 策略、工具权限与模型组合，实现按职责协作。
- **任务分类路由**：构建 Category 路由机制，根据任务类型自动选择最优模型、思考强度与执行链路，降低人工干预成本。
- **插件化增强架构**：通过 `openclaw.plugin.json` 与 `register(api)` 接口接入宿主，避免修改宿主源码，具备良好的可维护性与可移植性。
- **工具权限治理**：基于 Hook 对工具调用进行前置拦截与策略控制，支持按 agent 限制可用工具范围，提升执行安全性。
- **Skill 动态注入**：支持按任务加载项目级或用户级 Skill，将外部知识与规范动态注入 agent 上下文，增强任务适配能力。
- **并行 Background 执行**：支持将探索、研究类任务委派给后台 agent 并行处理，提高复杂任务吞吐与响应效率。
- **自愈与韧性设计**：面向错误恢复、模型切换、未完成任务续跑等场景设计恢复机制，提升系统稳定性与长任务可用性。
- **质量管控体系**：引入计划审查、代码审查、AI 输出质量检测与 Oracle 验证思路，为高风险任务提供多层质量保障。
- **多通道协同能力**：可运行于本地网关并连接 Discord、Slack、Telegram 等多类远程通道，适用于跨平台 AI 服务接入场景。
- **多 Provider 兼容**：支持对接 OpenAI、Anthropic、Google、Ollama 等多类模型提供方，具备较强的模型可替换性与扩展性。
