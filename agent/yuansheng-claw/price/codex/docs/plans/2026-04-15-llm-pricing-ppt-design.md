# LLM 定价汇报 PPT 设计文档

## 目标

基于现有调研文档 `2026-04-15-llm-pricing-and-usage-report.md`，生成一份适合正式汇报的 `.pptx` 文件，面向“管理层可读、技术负责人可落地”的双受众场景。PPT 需要能够直接用于会议演示，同时保留可编辑性，便于后续继续修改。

## 受众

- 管理层/老板：需要快速理解三家模型的成本、限制与推荐策略
- 技术负责人/架构师：需要看到 token 用量模型、限制差异和落地建议

## 输出物

- 主交付：`2026-04-15-llm-pricing-and-usage-report.pptx`
- 辅助脚本：使用 `python-pptx` 生成 PPT，确保后续可重复生成
- 验证结果：至少验证文件可打开、页数正确、核心标题与数据存在

## 页面结构

控制在 12 页左右，结构如下：

1. 标题页
2. 执行摘要
3. 三家模型价格总览
4. 三家模型限制总览
5. 20 人团队月度 token 基线模型
6. 分环节用量拆分
7. 基线月费测算
8. 模型分工建议
9. 成本控制抓手
10. 推荐落地路径
11. 风险与注意事项
12. 附录：来源与口径

## 视觉方向

- 风格：正式、简洁、咨询汇报风格
- 配色：深蓝、白底、橙色点缀
- 布局：大标题 + 关键数字卡片 + 对比表/图
- 图表：
  - 价格对比表
  - 限制对比表
  - 分环节 token 堆叠图
  - 成本区间对比图
  - 模型分工流程图

## 内容取舍原则

- 首页和摘要页只放“管理层必须记住的结论”
- 所有技术细节只保留会影响成本或选型的部分
- 不把 Markdown 报告逐条搬运到 PPT
- 每页控制在 3-5 个主 bullet，避免成为“文档截图”

## 生成方案

推荐直接使用 `python-pptx` 生成原生 `.pptx`：

- 优点：
  - 可编辑
  - 本地环境已具备 Python 依赖
  - 易于自动化验证页数、标题和数据
- 不采用：
  - 纯手工 LibreOffice 编辑：不可重复、难校验
  - HTML 转 PDF 再转 PPT：编辑性差

## 验证标准

- 成功生成 `.pptx`
- 幻灯片数量符合设计页数
- 关键页包含预期标题：
  - `执行摘要`
  - `价格总览`
  - `限制总览`
  - `月费测算`
- 关键数字已落盘：
  - `618.2M`
  - `5,102 元 ~ 6,252 元/月`
  - `$2,828 /月`

## 风险

- 中文字体在不同机器上可能替换，需要尽量选用通用字体
- `python-pptx` 原生图表样式有限，需要用版式和颜色控制观感
- 若图表过于复杂，优先保证信息清晰，而不是追求视觉炫技
