# Agent 3 根因报告模板设计任务

## 背景与目标

- 目标对象：源生 Claw 系统中的 Agent 3 性能异常根因诊断报告
- 输出要求：设计一份可直接复用的 Markdown 模板
- 设计目标：
  - 同时适配 Phase 1 / Phase 2 / Phase 3 三阶段能力演进
  - 对人类审阅者保持可复核
  - 对 Agent 4 保持结构化、可消费、可执行
  - 明确证据、假设、置信度、冲突项与后续动作

- [x] 在本文件末尾补充 review

## 设计原则

- 简洁优先：固定结构尽量稳定，避免章节漂移
- 证据优先：结论必须绑定指标、采样、代码位置或知识库依据
- 兼容演进：同一模板通过字段约束区分不同阶段，而不是维护三套模板
- 交接友好：必须显式给出 Agent 4 可执行的优化方向与验证建议

  3. 报告核心围绕异常筛选、指标对比、热点分析、知识映射、根因卡片、冲突缺口和 Agent 4 交接展开，证据链闭环完整
