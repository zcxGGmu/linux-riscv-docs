### 报告模板先出最小可用版

- 触发：用户反馈“这个模板有点复杂”
- 问题模式：在结构设计类任务里，先给了完整增强版模板，但没有先给最小核心版，导致首轮交付的信息密度过高
- 纠正规则：
  - 面向 Agent 报告、规范、模板时，默认先给 `lite` 版，只保留决策必须字段
  - 只有在用户明确要求完整版本，或 `lite` 无法支撑流程闭环时，再扩展为 full 版
  - 判断模板是否过重时，只问一个问题：删掉这一节后，会不会让人或下游 Agent 无法做决策
- 下次做法：
  - 先输出“一页式/最小版”
  - 再附“需要时再展开的扩展章节”
